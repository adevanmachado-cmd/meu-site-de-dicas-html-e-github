# 🌐 Guia Inicial para Criar um Site

Este é um projeto prático desenvolvido para aprender as etapas iniciais de criação, estruturação e publicação de um site na internet. O projeto serve como um guia interativo cobrindo desde a instalação das ferramentas básicas até o deploy público.

## 🚀 Tecnologias Utilizadas

O site foi construído utilizando as tecnologias fundamentais da web:
* **HTML5**: Estruturação semântica de todo o conteúdo e seções.
* **CSS3**: Estilização visual personalizada, incluindo regras de layout responsivo.
* **JavaScript**: Lógica simples para interação com o usuário (botão de conclusão de curso).

## 🛠️ Ferramentas e Aprendizados

Durante o desenvolvimento deste projeto, foram praticados os seguintes conceitos:
* Configuração do ambiente de desenvolvimento com o **Visual Studio Code**.
* Uso da extensão **Live Server** para testes em tempo real no navegador.
* Versionamento de código utilizando comandos básicos do **Git**.
* Hospedagem e publicação gratuita do site através do **GitHub Pages**.

## 💻 Como Executar o Projeto Localmente

Se você deseja visualizar ou modificar o projeto no seu computador, siga os passos abaixo:

1. **Clone este repositório**:
   ```bash
   git clone https://github.com
   ```
2. **Abra a pasta do projeto** no Visual Studio Code.
3. **Inicie o Live Server**:
   * Clique com o botão direito sobre o arquivo `index.html`.
   * Selecione a opção **"Open with Live Server"**.
4. O site abrirá automaticamente no seu navegador padrão.
