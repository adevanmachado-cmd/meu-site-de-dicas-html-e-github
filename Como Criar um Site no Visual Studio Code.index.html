Como Criar um Site no Visual Studio Code? Guia Inicial para Criar um Site

Aprenda HTML, Visual Studio Code e GitHub Pages

Instalação Projeto Código HTML GitHub

1. Instalação dos Programas

Visual Studio Code

  • Baixe e instale o VS Code.
  • É um editor gratuito utilizado para desenvolver sites.

Git

  • Instale o Git para enviar arquivos ao GitHub.
  • Mantenha as configurações padrão durante a instalação.

GitHub

  • Crie uma conta gratuita.
  • Ela será utilizada para publicar seu site na internet.

2. Criando o Projeto

  1. Crie uma pasta chamada meu-site.
  2. Abra a pasta no Visual Studio Code.
  3. Crie os arquivos:
    • index.html
    • style.css
    • script.js

3. Estrutura Básica do HTML

Copie e cole o código abaixo no seu arquivo index.html:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu Primeiro Site</title>
</head>
<body>
    <h1>Olá Mundo!</h1>
</body>
</html>

O arquivo index.html é a página principal do site. Este código cria uma página simples que exibe "Olá Mundo!" no navegador.

4. Visualizando o Site

Instale a extensão Live Server no VS Code.

  • Clique em Extensões.
  • Pesquise por Live Server.

5. Publicando no GitHub Pages

  1. Crie um repositório público.
  2. Abra o terminal do VS Code.
  3. Digite os comandos abaixo:
git init
git add .
git commit -m "Primeira versão"
git branch -M main
git remote add origin URL_DO_REPOSITORIO
git push -u origin main

Depois vá em:

  • Settings
  • Pages
  • Deploy from a Branch
  • Branch: main
  • Pasta: /(root)

Após alguns minutos, o GitHub fornecerá seu endereço. O link seguirá este padrão:

https://seunomedeusuario.github.io/nome-do-repositorio

Desafio Final

Adicione ao seu site:

  • Menu de navegação
  • Imagens
  • Vídeo do YouTube
  • Formulário de contato
  • Mapa do Google Maps
